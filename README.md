# HR_ANALYTICS
Developed an interactive HR Analytics Dashboard using Excel and Power BI to analyze employee attrition, income, demographics, and department-wise insights.

## Project Objective
The objective of this project is to analyze employee data, identify key factors affecting attrition and employee retention, and develop an interactive HR dashboard that provides meaningful insights to support effective HR decision-making.

## Process
- Collect and clean the employee HR data.
- Analyze employee details using PivotTables.
- Calculate KPIs such as total employees, attrition rate, and average salary.
- Create charts and slicers for interactive data visualization.
- Build the dashboard and identify key HR insights for decision-making.

## Questions (KPIs)
- What is the total number of employees in the organization?
- What is the total number of employees who left the company?
- What is the overall employee attrition rate?
- Which department has the highest attrition rate?
- Which job role has the highest employee attrition?
- How does salary level affect employee attrition?
- Does overtime influence employee attrition?
- Which age group has the highest attrition rate?
